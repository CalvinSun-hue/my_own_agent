# C 语言复习笔记

## 指针

指针是保存内存地址的变量。`int *p = &a;` 表示 p 里存的是 a 的地址，`*p` 就是 a 本身。

数组名在大多数表达式中会退化为指向首元素的指针，所以 `a[i]` 和 `*(a + i)` 是等价的。

函数参数默认按值传递；想在函数里修改调用者的变量，就要把它的地址（指针）传进去。

## 结构体

结构体把不同类型的数据组合成一个整体。用 `.` 访问结构体变量的成员，用 `->` 访问结构体指针的成员，`p->x` 等价于 `(*p).x`。

## 动态内存

`malloc` 申请堆内存，用完必须 `free`，否则就是内存泄漏。free 之后不要再使用这个指针（悬空指针），最好把它置为 NULL。

## 1. 这一阶段在学什么

**RAG**（Retrieval-Augmented Generation，检索增强生成）= 先从你自己的资料里"检索"相关片段，再交给模型"生成"回答。
模型不知道你笔记本里写了什么，也不可能把全部笔记塞进每次请求——所以先检索、后生成。

本阶段**只做"检索"这一半**（`notes.py`）：把笔记切成段落、按相关度排序、取最相关的几段。
"生成"那半在阶段 3 的 agent 里已经会了；本阶段**不接** agent（保持阶段目录自包含）。

技术上要掌握四件事：

1. **段落切分**：Markdown 按空行切段；标题要拼到它下面段落的开头（否则搜"指针"时正文段落匹配不上标题信息）；
2. **字符二元组（bigram）**：中文没有空格分词，用"相邻两个字"当检索单位——"数组指针" → {数组, 组指, 指针}；
3. **打分与排序**：query 的 bigram 集合与段落 bigram 集合的**重合比例**当分数，降序取前 `top_k`；
4. **路径安全**：`read_file` 只能读笔记目录里的文件，防止 `../.env` 这种"路径逃逸"。

## 3. 部件清单（5 组，一个都不能少）

| # | 部件 | 输入 | 输出 | 关键点 / 边界 |
|---|---|---|---|---|
| 1 | `Chunk`（`@dataclass`） | — | 一个片段对象 | 字段 `file: str`（相对路径）、`text: str`、`score: float = 0.0` |
| 2 | `_bigrams(text)` | 一段文字 | `set[str]`（相邻两字的集合） | 先 `lower()` 并去掉所有空白；**长度 1 的文字**返回 `{它本身}`；空串返回空集合 |
| 3 | `load_chunks(notes_dir)` | 笔记目录 | `list[Chunk]` | 只收 `.md` / `.txt`（大小写不敏感）；`notes_dir` 不存在 → `[]`；按空行切段；单独的标题行不单独成段，而是"记住"并拼到后面段落前；`file` 用相对路径（`/` 分隔）；坏字节不崩（`errors="ignore"`） |
| 4 | `search(notes_dir, query, top_k=3)` | 目录 + 查询词 | `list[Chunk]`（已排序） | 只保留有重合的段；分数 = 重合 bigram 数 ÷ query bigram 数；降序；空 query / 全是空白 → `[]`；没有命中 → `[]`（**不抛异常**） |
| 5 | `list_files(notes_dir)` / `read_file(notes_dir, name, max_chars=4000)` | 目录 / 目录 + 文件名 | `list[str]` / `str` | `list_files` 只列笔记文件、按路径排序、返回相对路径；`read_file` 要**防路径逃逸**（解析后必须仍在笔记目录内），读不到 → `FileNotFoundError`，超长 → 截断并注明总字数 |

## 4. 边界清单（测试会逐条打）

- 目录不存在 / 空目录：返回空列表，不崩
- 文件后缀：`.md`、`.txt` 收；`.py`、`.json` 不收；`.MD` 也要收
- 空行切段；标题行的归属
- 单字 query、空 query、全空白 query、无命中 query
- 中文文件名（`C语言-指针与内存.md`）与中文内容
- `read_file`：正常文件 / `../` 逃逸 / 文件不存在 / 超长截断
- 返回路径用 `/`（`as_posix`），不能用 `\`

## 5. 验收标准（这些行为以后会变成测试，先读一遍心里有数）

> 以下每条都在参考实现上实测过，是"必须成立"的行为；你的实现只要满足它们，测试就能绿。

1. `list_files` 返回三个样例文件名，顺序稳定（排序后）
2. `load_chunks` 只收 `.md/.txt`；目录不存在时返回 `[]`
3. 每个 chunk 的 `text` 里，正文前面带着它所属的标题（如 `指针：数组名在大多…`）
4. `search(..., "数组和指针的关系")` 的第一条来自 `C语言-指针与内存.md`
5. `search(..., "极限的定义")` 的第一条来自 `高数-极限与导数.md`，且分数为 1.0
6. `search(..., "内存泄漏")` 命中 C 笔记的"动态内存"段
7. `search(..., "")`、`search(..., "   ")`、`search(..., "量子力学")` 都返回 `[]`，不抛异常
8. 分数降序：`[c.score for c in hits]` 单调不增
9. `top_k` 生效：传 `top_k=1` 只返回 1 条
10. `read_file` 正常返回全文
11. `read_file("..\\C语言-指针与内存.md")`、`read_file("../ref_check.py")` 这类**逃逸到目录外**的路径抛 `ValueError`
12. `read_file("不存在的笔记.md")` 抛 `FileNotFoundError`
13. `read_file(..., max_chars=10)` 截断，并包含"已截断"和总字数提示
